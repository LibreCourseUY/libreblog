Codenights are back\! And with superb achievements\!

This codenight lasted about 5 hours (1800 to 2300).

We first discussed advances in [**UruAPI**](https://github.com/LibreCourseUY/UruAPI), our newest project focused on delivering Uruguay’s daily-updated economic indicators in a JSON-friendly format.

We then went to talk about the recent efforts by LibreCourse’s members in the development of the Uruguayan DNIe (cédula de identidad) signature ecosystem. The first of these efforts being the creation of the open-source tool [**firmauy**](https://github.com/carlosplanchon/firmauy), providing an easy way to sign and verify signatures for any file format. 

On the same line, work has been done on a [**PR**](https://github.com/OpenSC/OpenSC/pull/3729) to add support for the Uruguayan DNIe in OpenSC, an open-source middleware for working with smartcards. Currently the PR is in the final testing phase, but has been already approved by 2 maintainers.

If everything works out well, we will soon see the uruguayan cédula supported. And this is only the beginning; big things are coming this way, so remain on frequency\!
