Here's what actually mattered in tech this week (October 5 to 12, 2026).

### Tech News

#### Linux

- **Linus Torvalds** revealed he used **Claude Code** to draft kernel patches and make complex code more decipherable, noting that the AI assistant successfully helped uncover hidden bugs as reported by [Phoronix](https://www.phoronix.com/news/Linus-Torvalds-Assoc-Array).
- The upcoming **Linux 7.4 kernel** will add upstream support for several **Snapdragon X2 Elite** laptops from brands like ASUS, HP, and Lenovo, according to [Phoronix](https://www.phoronix.com/news/ASUS-UX3407NA-Linux-7.4).
- **EXT4** introduced an opt-in **IOmap buffered I/O** path for Linux 7.4, replacing legacy buffer_head usage to deliver performance gains, as detailed by [Phoronix](https://www.phoronix.com/news/EXT4-iomap-Buffered-IO).
- Mozilla released **Firefox 158** with **JPEG-XL** support finally enabled by default, continuing their bi-weekly release rhythm covered by [Phoronix](https://www.phoronix.com/news/Firefox-158-Released).

#### AI / Dev Tools

- **Meta** launched its first frontier models, **Muse Wonder** and **Muse Wonder Full**, which feature higher benchmark scores and stronger coding capabilities than previous iterations, as covered by [TechCrunch](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/) and [The Verge](https://www.theverge.com/ai-artificial-intelligence/1009479/meta-muse-wonder-full-ai-model).
- **OpenAI's Codex CLI** sparked backlash after users discovered it installs a persistent, self-updating background daemon by default, documented in a GitHub issue highlighted by [Hacker News](https://github.com/openai/codex/issues/48195).
- **GitHub** published a guide on setting up custom agents, repo instructions, and connecting MCP servers like **Playwright** for the GitHub Copilot app, featured on [The GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/).
- Research highlighted by [Ars Technica](https://arstechnica.com/ai/2026/10/ai-coding-agents-generate-more-code-but-not-more-software/) noted that while AI coding agents generate significantly more raw code, they are not actually increasing total completed software output.

#### Infrastructure & Hardware

- **Intel** announced the **GPU D Series** under the codename **Crescent Island**, targeting enterprise-focused and inference-optimized workloads, according to [Phoronix](https://www.phoronix.com/news/Intel-GPU-D-Series).
- **Cloudflare** introduced **Transformers on Logpush**, powered by **Apache DataFusion** and **Apache Arrow**, allowing engineering teams to filter and redact log streams using SQL before export, as announced on the [Cloudflare Blog](https://blog.cloudflare.com/transformers-on-logpush/).
- **AMD** unveiled its new **Helion racks** tailored for AI agents at the Open Compute Project summit, with CPU and mixed configurations scheduled from partners via [The Register](https://www.theregister.com/systems/2026/10/12/amd-unveils-helion-racks-for-ai-agents-at-ocp-summit/5302652).

#### Security & Platforms

- **Microsoft** blamed an internal configuration change for a major tumble in the **Exchange Admin Center**, which required a full rollback to resolve, reported by [The Register](https://www.theregister.com/saas/2026/10/12/microsoft-blames-a-configuration-change-for-exchange-admin-center-tumble/5302698).
- Ukrainian drone strikes targeting **Yandex data centers** knocked cloud and payment services offline in Russia, plunging network connectivity down to 30 percent of normal levels according to [The Register](https://www.theregister.com/security/2026/10/12/ukrainian-drone-strikes-on-yandex-datacenters-knock-cloud-and-payments-offline/5302577).
- **Microsoft** reportedly patched the easiest Windows 11 local account setup bypass server-side, forcing users looking to avoid mandatory online accounts to rely on more complex workarounds as covered by [The Register](https://www.theregister.com/os-platforms/2026/10/12/windows-11s-easiest-account-bypass-gets-the-microsoft-boot/5302643).
